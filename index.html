El Concepto

Marcador de Emergencia

Un dispositivo autónomo que, al presionar un botón físico, realiza automáticamente una llamada de voz a un número predefinido. Sin pantalla, sin teclado, sin complicaciones.

🔧

Componentes Clave

  1. Arduino UNO / Nano
  2. Módulo GSM SIM800L
  3. Reductor LM2596 (4V)
  4. Micrófono + altavoz
  5. Un botón momentáneo

¿Cómo Funciona?

Click para ver más

Comandos AT

El Arduino envía comandos AT al módulo GSM vía Serial (TX/RX). Con ATD+número; inicia la llamada y con ATH; la corta.

Energía

Fuente de Poder

El SIM800L exige una fuente externa estable. Nunca uses el pin 5V del Arduino: las llamadas consumen picos de corriente que reinician el micro.

🎙️

Audio

Calidad de Voz

Usa micrófonos de condensador soldados cerca de la placa para evitar interferencias del módulo GSM (ruido "clic-clic" clásico). Antena helicoidal o externa recomendada.

// Muestra de código

El Comando Esencial

Toda la magia ocurre en tres líneas. El Arduino abre comunicación serial con el módulo y le ordena marcar el número. 

// Iniciar llamada
Serial.println("ATD+5411XXXXXXXX;");

// Esperar...

// Colgar
Serial.println("ATH;");

El punto y coma final en ATD le indica al módulo que es una llamada de voz, no de datos.

TX → SIM800L

ATD+54911234567;
OK
CONNECT

Botón físico

Un simple digitalRead(PIN_BOTON) dispara la secuencia. Al soltar o presionar de nuevo, envía ATH;.
